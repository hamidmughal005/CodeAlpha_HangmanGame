# Hangman Game – Python

## Project Description
This is a text-based Hangman Game developed using Python as part of the **CodeAlpha Python Programming Internship**.

In this game, the computer randomly selects a word from a predefined list, and the player has to guess the word one letter at a time. The player gets a maximum of 6 incorrect guesses before losing the game.

## Features
- Random word selection.
- Seven predefined words.
- Interactive letter guessing.
- ASCII Hangman drawings that update with incorrect guesses.
- Hidden word display using underscores.
- Correct and incorrect guess tracking.
- Duplicate letter detection.
- Input validation.
- Maximum 6 wrong guesses.
- Win and lose conditions.
- Displays the correct word when the player loses.

## How to Play
1. Run the Python program.
2. The computer randomly selects a hidden word.
3. Enter one alphabet letter at a time.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses update the Hangman drawing.
6. Avoid making 6 incorrect guesses.
7. Guess the complete word to win!

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python hangman.py
```
